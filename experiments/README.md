# Experiments

A space to test ideas safely before committing them to the main project.

## Rules

- Each experiment lives in its own numbered directory: `NNN-short-name/`
- Every experiment starts with a `README.md` that states the hypothesis and pass/fail criteria **before** any work is done
- Nothing outside `experiments/` is touched until an experiment graduates
- If it works: the output moves to the right place in the project, the experiment dir stays as a record
- If it doesn't: it sits here, nothing is tainted, next experiment

## Graduation

An experiment graduates when its success criteria are met. The output (a document, a script, a design) moves to its permanent home. The experiment README gets an **Outcome** section recording what was learned.
