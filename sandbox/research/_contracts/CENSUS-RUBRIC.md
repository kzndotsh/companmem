# Companion memory census rubric

Delegates fill cards. They do not edit this file.

The user is a person who talks to one companion for months. Winning LoCoMo is not the job. The job is that the companion still feels like the same person, remembers the relationship, stays quiet when recall would be creepy, and does not get hijacked by poisoned writes.

## Shared premise to test, not assume

Most agent-memory products assume this sentence.

If we retrieve the right past text or extracted facts into the prompt, the model will act as if it remembers the relationship.

Every card must say whether the system assumes that sentence, and what evidence shows it.

## Required sources

Primary only, in this order.

1. Official docs. Prefer `llms.txt` or `llms-full.txt` on the vendor site.
2. Source in the GitHub repo. Name the file and the symbol. Do not cite a blog that paraphrases the repo.
3. The system's own paper, if any.
4. The eval they publish numbers on, plus what that eval actually scores.

Secondary blogs, SEO roundups, and Discord hearsay are `guess` unless you can point at a primary page that says the same thing.

Closed products (Kindroid, Nomi, Character.AI, Replika) have no public engine. Mark internals `INCONCLUSIVE`. Cite official help docs only. Do not treat companion-review sites as specs.

## Card files

Write one JSON file per player to `research/census/cards/<id>.json`.

Match `research/_contracts/card.schema.json`. Extra keys are forbidden.

Also write one markdown file for the slice you were assigned, at the path in your brief. The markdown is a reading path. The JSON is the record.

In every markdown claim, label the sentence `measured`, `inferred`, or `guess` in the same sentence.

## Dimensions every card must fill

Score each dimension `present`, `partial`, `absent`, or `unknown`.

Unknown is allowed. Pretending you saw the code is not.

1. `ontology`. Typed memory kinds as types or tables, not slogans. User bio, character autobiography, relationship state, world lore, session working memory, OOC notes. Name the actual types.
2. `write_policy`. Who decides what is stored. User pin, model extract, agent tool, keyword lore, background deriver. What is refused.
3. `read_policy`. Who decides what is injected this turn. Always-on block, top-k vector, keyword, dialectic query, model tool call. When the system is allowed to retrieve nothing.
4. `supersession`. How a new fact replaces an old one. Delete, overwrite, invalidate-with-time, keep both, ignore.
5. `temporal`. Validity windows, session timestamps, "last Tuesday" queries.
6. `identity_split`. Can the store tell the user, the character, and the relationship apart, or is it one `user_id` bag of facts.
7. `silence`. Controls for not recalling something that is relevant by embedding score (trauma, kink, spoilers, jokes).
8. `poisoning`. Stored text that later jailbreaks, overwrites persona, or plants false relationship state. Any filter, provenance, or trust tags.
9. `forgetting`. User "forget that", decay, repression, summarization that drops detail.
10. `cost_shape`. LLM calls per turn for extract and retrieve. Embedding calls. Graph writes. Token budget into the companion prompt.
11. `local`. Can intimate chat stay on one machine with no vendor API. License that actually allows it.
12. `mcp`. Official MCP server, community only, or none.
13. `published_eval`. Name, score they claim, and the ability the eval scores. If the eval is fact QA on assistant chat, say so.
14. `companion_fit`. `FIT`, `PARTIAL`, or `MISFIT` for long-term companion and roleplay. Justify from the dimensions above, not from star count.

## Verdicts

The slice markdown ends with a table of player id, `companion_fit`, and one-line reason.

The worker report to the parent is `PASS`, `ISSUES`, or `BLOCKED`.

- `PASS` if every assigned player has a valid JSON card and the markdown names a primary source for each non-unknown dimension that is not unknown.
- `ISSUES` if some players are partial but the gaps are listed.
- `BLOCKED` if you could not reach primary sources.

Do not clone their architecture into a proposal. Census only.
