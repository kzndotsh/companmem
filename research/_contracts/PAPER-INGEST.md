# Paper ingest contract

Delegates fill cards. They do not edit this file.

A friend list is not a protocol. Most of these papers are not companion memory systems. Score them. Do not stuff every mechanism into the later engine.

## Shared premise to test, not assume

If we retrieve the right past text or extracted facts into the prompt, the model will act as if it remembers the relationship.

Weight-space memory, hippocampal graphs, persona vectors, and lifecycle merge are still that premise if the companion turn is "retrieve then speak."

## Bands

`research/papers/registry.json` is the index. Every listed arXiv id or DOI must appear.

- `core`. A memory, persona, identity, or forgetting system we can audit. Gets a census card under `research/census/cards/<id>.json`.
- `adjacent`. Steal one idea. No card. One `steal` sentence in the registry is the record.
- `out-of-scope`. Wrong domain. One `why_band` sentence. No card.

Do not promote a paper to `core` because the title contains "memory." SciBORG is a lab-agent FSA. Visual-RAG is image QA. Robot 3DGS is morphology.

## Card rules

Same schema as `research/_contracts/card.schema.json`. `kind` is `academic`.

Primary sources only, in this order.

1. Local extract `research/papers/arxiv/<id>.md` (arXiv MCP cache, HTML first, PDF if HTML is missing).
2. The paper's GitHub, named file and symbol.
3. The eval they publish numbers on, plus what that eval actually scores.

Abstracts are not enough for a `core` card. Read methods and eval sections.

MemGPT is already reflected in the Letta product card. The MemGPT card is historical. Current Letta is MemFS. Do not treat core/recall/archival as current.

## Slice files

Each worker writes only the markdown path in its brief. JSON is the record. Markdown is the reading path.

Label every markdown claim `measured`, `inferred`, or `guess` in the same sentence.

## Check

`python3 research/_contracts/validate-papers.py` must pass. It requires every registry `core` id to have a valid census card, and forbids cards for `out-of-scope` ids.
