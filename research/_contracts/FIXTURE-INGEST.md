# Fixture ingest contract

Delegates fill fixtures. They do not edit this file.

A fixture is a Harbor-shaped task. It is not a LoCoMo probe with extra prose.

## Layout

```
research/evals/fixtures/<id>/
  fixture.json
  task.toml
  instruction.md
  environment/world/     # agent-visible
  solution/solve.sh
  solution/gold_reply.txt
  solution/gold_memory_export.json
  tests/predicates.json  # hidden exam
  tests/test.sh
```

`research/_contracts/fixture-ids.txt` is the index. Every listed id must exist.

## Visible vs hidden

`instruction.md` and `environment/world/` are what the system may see.

`tests/predicates.json` and `solution/gold_*.txt` are not. The instruction must not paste the gold reply. The next user line must not be "what is my X?"

## Checks

`python3 research/_contracts/validate-fixtures.py` must pass.

`python3 research/_contracts/run-oracles.py` must show oracle PASS and naive FAIL on every public fixture.

Do not implement the unit 5 runner in this contract.
